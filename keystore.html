# מדריך הגדרת Keystore לחתימת אפליקציית אנדרואיד (FlexiBiz) כדי להעלות את האפליקציה ל-Google Play, עליך לחתום אותה בגרסת Release. הנה השלבים לביצוע: ## 1. יצירת קובץ ה-Keystore פתח את הטרמינל בתיקיית השורש של הפרויקט והרצ את הפקודה הבאה: ### ב-Windows: ```bash keytool -genkey -v -keystore c:\Users\USER_NAME\upload-keystore.jks ^ -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 ^ -alias upload ``` *(החלף את USER_NAME בשם המשתמש שלך במחשב)* ### ב-macOS / Linux: ```bash keytool -genkey -v -keystore ~/upload-keystore.jks \ -keyalg RSA -keysize 2048 -validity 10000 \ -alias upload ``` **חשוב:** במהלך התהליך תתבקש להזין סיסמה. **זכור אותה היטב!** בלעדיה לא תוכל לעדכן את האפליקציה בחנות בעתיד. --- ## 2. יצירת קובץ ההגדרות `key.properties` צור קובץ חדש בשם `key.properties` בתוך תיקיית `android/` (לא בתוך `app/`) והוסף בו את התוכן הבא: ```properties storePassword=הסיסמה_שלך keyPassword=הסיסמה_שלך keyAlias=upload storeFile=C:\\Users\\USER_NAME\\upload-keystore.jks (או הנתיב ב-Mac) ``` --- ## 3. הגדרת ה-Gradle לחתימה ערוך את הקובץ `android/app/build.gradle`. ### א. הוסף את קריאת הקובץ (לפני הבלוק של `android`): ```groovy def keystoreProperties = new Properties() def keystorePropertiesFile = rootProject.file('key.properties') if (keystorePropertiesFile.exists()) { keystoreProperties.load(new FileInputStream(keystorePropertiesFile)) } ``` ### ב. הגדר את ה-Signing Config: בתוך בלוק `android { ... }`, הוסף/עדכן: ```groovy signingConfigs { release { keyAlias keystoreProperties['keyAlias'] keyPassword keystoreProperties['keyPassword'] storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null storePassword keystoreProperties['storePassword'] } } buildTypes { release { signingConfig signingConfigs.release // ... הגדרות נוספות כמו shrinkResources ו-minifyEnabled } } ``` --- ## 4. אבטחה (חשוב מאוד!) **אל תעלה את קבצי ה-Keystore או ה-key.properties ל-GitHub!** הוסף אותם לקובץ ה-`.gitignore` שלך: ```text **/android/key.properties *.jks ``` --- **טיפ של Stitch:** שמור גיבוי של קובץ ה-`.jks` במקום בטוח (כמו Google Drive או כספת סיסמאות). אם תאבד אותו, לא תוכל לעדכן את האפליקציה בחנות לעולם!
