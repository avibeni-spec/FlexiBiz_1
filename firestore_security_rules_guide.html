# Firestore Security Rules for FlexiBiz To ensure that your data is safe and that users can only access what they are supposed to, you must deploy these security rules in your Firebase Console. ```javascript rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Helper: Is the user a logged-in manager? function isManager() { return request.auth != null && get(/databases/$(database)/documents/managers/$(request.auth.uid)).data.role == 'manager'; } // Helper: Is the user the owner of the client document? function isOwner(clientId) { return request.auth != null && request.auth.uid == clientId; } // --- CLIENTS COLLECTION --- match /clients/{clientId} { allow read, write: if isManager(); allow read: if isOwner(clientId); allow create: if request.auth != null; // Allow initial registration } // --- APPOINTMENTS COLLECTION --- match /appointments/{appointmentId} { allow read, write: if isManager(); allow create: if request.auth != null; allow read, update: if request.auth != null && resource.data.clientId == request.auth.uid; } // --- BUSINESS COLLECTION --- match /businesses/{businessId} { allow read: if true; // Publicly readable for client app allow write: if isManager(); } // --- SERVICES COLLECTION --- match /services/{serviceId} { allow read: if true; allow write: if isManager(); } // --- SPECIALISTS COLLECTION --- match /specialists/{specialistId} { allow read: if true; allow write: if isManager(); } } } ``` ## How to Deploy: 1. Go to the **Firebase Console**. 2. Select **Firestore Database** from the left menu. 3. Click on the **Rules** tab. 4. Paste the code above and click **Publish**.
