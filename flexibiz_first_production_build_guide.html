# FlexiBiz - First Production Build Guide This document provides the final, consolidated steps to generate your first production-ready builds for both the Manager and Client apps. ## 1. Final Project Audit Before running the build commands, ensure these three pillars are solid: * **Firebase Config:** Your `google-services.json` (Android) and `GoogleService-Info.plist` (iOS) must be in their respective `app` and `Runner` folders. * **Main Entry Point:** Your `lib/main.dart` should match the **Final Release Build Configuration** to ensure all providers and the global loading state are active. * **Security Rules:** Confirm that your **Firestore Security Rules** are published in the Firebase Console to prevent data leaks. ## 2. Android Build (App Bundle) Google Play requires the `.aab` format for all new apps. This command also obfuscates your code to protect your business logic. ```bash # Clean the project first flutter clean flutter pub get # Generate the release App Bundle flutter build appbundle --release --obfuscate --split-debug-info=./debug_info ``` *The resulting file will be at: `build/app/outputs/bundle/release/app-release.aab`* ## 3. iOS Build (IPA) For iOS, you will generate the build and then use Xcode to upload it to App Store Connect. ```bash # Build the iOS release (no codesign for now, will sign in Xcode) flutter build ios --release --no-codesign ``` **Steps in Xcode:** 1. Open `ios/Runner.xcworkspace`. 2. Select **"Any iOS Device (arm64)"** as the target. 3. Go to **Product > Archive**. 4. Once finished, click **"Distribute App"** and follow the prompts to upload to TestFlight or the App Store. ## 4. Post-Build Testing Checklist Once you have the build, test these "Golden Flows" on a real device: 1. **Cold Start:** Does the app open smoothly to the Dashboard? 2. **Cloud Sync:** Add a client on one device; does it appear on the other within 2 seconds? 3. **Global Loading:** Does the golden spinner appear during a "Save" action? 4. **Notifications:** Set a test appointment; do you receive the push reminder? **FlexiBiz is now technically a reality. You are ready to ship!**
