# מדריך פקודות Build בטרמינל עבור FlexiBiz מדריך זה מרכז את הפקודות שצריך להריץ בטרמינל כדי לייצר גרסאות הפצה (Release) של האפליקציה. ## 1. שלב ההכנה (Pre-Build) לפני כל Build, חשוב לנקות את הפרויקט ולוודא שכל החבילות מעודכנות. ```bash # ניקוי קבצים זמניים ושאריות מגרסאות קודמות flutter clean # הורדת כל התלויות (Packages) מחדש flutter pub get ``` --- ## 2. בנייה לאנדרואיד (Android - AAB) גוגל דורשת פורמט `.aab` להעלאה לחנות. אנחנו משתמשים גם ב-Obfuscation כדי להגן על הקוד. ```bash # פקודה ליצירת App Bundle (הפורמט המומלץ לחנות) # --release: בונה גרסת הפצה אופטימלית # --obfuscate: מערבל את הקוד כדי להקשות על הנדסה לאחור # --split-debug-info: שומר את המידע לדיבאג בקובץ נפרד להקטנת נפח האפליקציה flutter build appbundle --release --obfuscate --split-debug-info=./debug_info ``` *הקובץ ייווצר בכתובת: `build/app/outputs/bundle/release/app-release.aab`* --- ## 3. בנייה ל-iOS (iPhone - IPA) עבור iOS, אנחנו מייצרים את ה-Build ואז משתמשים ב-Xcode להעלאה הסופית. ```bash # בניית הגרסה ל-iOS (ללא חתימה, נבצע חתימה בתוך Xcode) flutter build ios --release --no-codesign ``` **השלבים הבאים ב-Xcode:** 1. פתח את הקובץ `ios/Runner.xcworkspace`. 2. בחר ב-**Product > Archive**. 3. בסיום, לחץ על **Distribute App** ובחר ב-**App Store Connect**. --- ## 4. פקודות עזר שימושיות ### בדיקת ביצועים בזמן אמת (Release Mode): כדי לראות איך האפליקציה מתנהגת על מכשיר אמיתי בגרסה הסופית: ```bash flutter run --release ``` ### עדכון גרסה ב-pubspec.yaml: אל תשכח לעדכן את מספר הגרסה לפני כל Build חדש לחנות: `version: 1.0.0+1` (המספר שאחרי ה-`+` חייב לעלות בכל העלאה). --- **טיפ של Stitch:** וודא שחיברת את המכשיר הפיזי שלך או שהגדרת את ה-Keystore (באנדרואיד) לפני הרצת הפקודות. בהצלחה!
