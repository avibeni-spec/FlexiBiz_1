# FlexiBiz Logic & Firestore Integration Guide This document details how to connect the Flutter UI to Firebase Firestore and manage application state. ## 1. Firebase Setup Requirements Before implementing the code, ensure you have: 1. Created a Firebase project at [console.firebase.google.com](https://console.firebase.google.com). 2. Added your Android/iOS/Web apps to the Firebase project. 3. Added the necessary dependencies to your `pubspec.yaml`: ```yaml dependencies: firebase_core: ^latest_version cloud_firestore: ^latest_version firebase_auth: ^latest_version # Optional for login flutter_riverpod: ^latest_version # Recommended for State Management ``` ## 2. Core Firestore Service (`database_service.dart`) This service handles all direct interactions with the database. ```dart import 'package:cloud_firestore/cloud_firestore.dart'; import '../models/client_model.dart'; import '../models/appointment_model.dart'; class DatabaseService { final FirebaseFirestore _db = FirebaseFirestore.instance; // --- CLIENTS --- // Get all clients as a stream for real-time updates Stream> streamClients() { return _db.collection('clients').snapshots().map((snapshot) => snapshot.docs.map((doc) => Client.fromMap(doc.data())).toList()); } // Add or update a client Future saveClient(Client client) async { await _db.collection('clients').doc(client.id).set(client.toMap(), SetOptions(merge: true)); } // Delete a client Future deleteClient(String clientId) async { await _db.collection('clients').doc(clientId).delete(); } // --- APPOINTMENTS --- // Stream appointments for a specific date Stream> streamAppointmentsForDate(DateTime date) { String dateStr = DateTime(date.year, date.month, date.day).toIso8601String(); return _db.collection('appointments') .where('dateOnly', isEqualTo: dateStr) .snapshots() .map((snapshot) => snapshot.docs.map((doc) => Appointment.fromMap(doc.data())).toList()); } // Create a new appointment Future createAppointment(Appointment appointment) async { await _db.collection('appointments').doc(appointment.id).set(appointment.toMap()); } // Update appointment status Future updateAppointmentStatus(String id, String status) async { await _db.collection('appointments').doc(id).update({'status': status}); } // --- BUSINESS PROFILE --- // Get business data Stream> streamBusinessInfo(String businessId) { return _db.collection('businesses').doc(businessId).snapshots().map((doc) => doc.data() ?? {}); } // Update business profile Future updateBusinessProfile(String id, Map data) async { await _db.collection('businesses').doc(id).update(data); } } ``` ## 3. State Management with Riverpod Riverpod allows us to easily access the `DatabaseService` and cache the data. ```dart import 'package:flutter_riverpod/flutter_riverpod.dart'; // Providers for services final databaseProvider = Provider((ref) => DatabaseService()); // Streams as Providers final clientsStreamProvider = StreamProvider>((ref) { return ref.watch(databaseProvider).streamClients(); }); final appointmentsStreamProvider = StreamProvider.family, DateTime>((ref, date) { return ref.watch(databaseProvider).streamAppointmentsForDate(date); }); ``` ## 4. Connecting UI to Firestore (Example: Clients List) How to use the `StreamProvider` in your `ClientsScreen`. ```dart class ClientsScreen extends ConsumerWidget { @override Widget build(BuildContext context, WidgetRef ref) { final clientsAsync = ref.watch(clientsStreamProvider); return Scaffold( body: clientsAsync.when( data: (clients) => ListView.builder( itemCount: clients.length, itemBuilder: (context, index) => ClientCard(client: clients[index]), ), loading: () => Center(child: CircularProgressIndicator()), error: (err, stack) => Center(child: Text('Error: $err')), ), ); } } ``` ## 5. Next Steps 1. **Initialize Firebase** in your `main.dart`. 2. **Create the Models** (`client_model.dart`, etc.) if you haven't already. 3. **Wrap your app** in a `ProviderScope`.
